# LukyBends

A *Heads Up! / Charades*-style party web game built with pure HTML, CSS, and JavaScript.

## Features (English)

- **Themed Categories & Weighted Points:** Guess words across themed decks where each word carries 1–3 points based on difficulty.
- **Mobile & PC Modes:** Play with touch/tilt on mobile or keyboard controls on desktop.
- **Configurable Timer:** Choose 30s, 60s, 90s, 120s, 150s, or play without a time limit.
- **Custom Categories:** Create your own word decks with custom point values.
- **Web Audio Sound Effects:** Synthesized audio cues for correct guesses, passes, and countdowns.

## Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser (no build step required).
3. Select your mode, timer, and category, then start guessing!

# LukyBends (Česky)

Párty webová hra ve stylu *Heads Up! / Šarády*, vytvořená v čistém HTML, CSS a JavaScriptu.

## Funkce

- **Tematické kategorie a bodování:** Hádejte slova v různých kategoriích, kde každé slovo má hodnotu 1–3 body podle obtížnosti.
- **Režim Mobil i PC:** Hrajte na telefonu nebo na počítači.
- **Nastavitelný časovač:** Vyberte si 30 s, 60 s, 90 s, 120 s, 150 s nebo hru bez časového limitu.
- **Vlastní kategorie:** Vytvořte si vlastní balíčky slov s vlastními body.
- **Zvukové efekty (Web Audio API):** Syntetizované zvuky pro správné odpovědi, přeskočení a odpočet.

## Jak hrát

1. Naklonujte nebo stáhněte repozitář.
2. Otevřete `index.html` v libovolném moderním prohlížeči (bez nutnosti instalace).
3. Vyberte režim, časovač a kategorii a začněte hádat!
