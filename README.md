# LukyBends

> **English** | [Čeština](#čeština)

A modern, Apple-style *Heads Up! / Charades* party web game built with pure HTML5, CSS3, and JavaScript with zero external dependencies.

## Features (English)

- **Apple HIG Design:** Sleek iOS/macOS interface with fluid spring animations, frosted glass modals, and responsive controls.
- **Light & Dark Theme:** Built-in theme switcher supporting automatic system detection and manual toggle.
- **Themed Categories & Weighted Points:** 12 curated word decks where words carry 1–3 points based on difficulty.
- **Mobile & PC Modes:** Play with split touch taps on mobile or keyboard controls (arrows/space) on PC.
- **Custom Word Decks:** Easily create and save custom word decks with individual point weights directly in `localStorage`.
- **Configurable Timer:** Choose 30s, 60s, 90s, 120s, 150s, or play without a time limit (∞).
- **Web Audio Sound Effects:** Synthesized audio cues for countdowns, correct guesses, passes, and finish with a mute toggle.
- **Zero External Dependencies:** Built with inline SF-style SVG icons for instant loading, full offline support, and zero third-party CDNs.

## Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser (no build step required).
3. Select your mode, timer, and category, then start guessing!

## Čeština

Moderní společenská webová hra ve stylu *Heads Up! / Šarády* v Apple stylu, vytvořená v čistém HTML5, CSS3 a JavaScriptu bez jakýchkoliv externích závislostí.

### Funkce

- **Apple HIG design:** Čistý vzhled inspirovaný systémem iOS a macOS s pružnými animacemi, poloprůhlednými modálními okny a kartami.
- **Světlý a tmavý režim:** Plná podpora přepínání témat s automatickou detekcí systémových preferencí a manuálním přepínačem.
- **Tematické kategorie a bodování:** 12 předpřipravených balíčků se slovy ohodnocenými 1–3 body podle obtížnosti.
- **Režim Mobil i PC:** Hrajte dotykem na displej telefonu (levá strana = správně, pravá = přeskočit) nebo pomocí klávesnice na PC.
- **Vlastní balíčky slov:** Vytvářejte vlastní kategorie slov s vlastními body, které se spolehlivě ukládají do zařízení.
- **Nastavitelný časovač:** Volba 30 s, 60 s, 90 s, 120 s, 150 s nebo hra bez časového limitu (∞).
- **Zvukové efekty (Web Audio API):** Syntetizované zvuky pro odpočet, správné odpovědi a přeskočení s možností ztlumení.
- **Bez externích závislostí:** Všechny ikony jsou přímo v SVG (SF styl), hra běží 100% offline a bez externích knihoven.

### Jak hrát

1. Naklonujte nebo stáhněte repozitář.
2. Otevřete `index.html` v libovolném moderním prohlížeči (bez nutnosti instalace).
3. Vyberte režim, časovač a kategorii a začněte hádat!
